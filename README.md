# 💰 Personal Expense Tracker

A lightweight, responsive web application for tracking daily income and expenses. Built with standard web technologies and Chart.js, featuring local storage persistence, multi-criteria filtering, and visual category breakdowns.

🌐 **Live Demo:** [https://ansonmathai.github.io/expense-tracker-anson-mathai/](https://ansonmathai.github.io/expense-tracker-anson-mathai/)

---

## ✨ Features

* **Financial Overview:** Track real-time total balance, total income, total expenses, and month-specific expense totals.
* **Transaction Management:** Complete CRUD functionality to add, edit, and delete income or expense entries with input validation.
* **Category Breakdown:** Interactive doughnut chart powered by Chart.js displaying expense distribution across categories.
* **Dynamic Filtering:** Filter transaction history by type (*Income/Expense*), category search, or custom date ranges (*From/To*).
* **Local Storage Persistence:** All transaction history is preserved locally in your browser across sessions.

---

## 🛠️ Built With

* **HTML5** & **CSS3**
* **Vanilla JavaScript (ES6+)**
* **Chart.js** (via CDN)
